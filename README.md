**Вариант 6.** Риск отчисления студентов — набор *Predict Students' Dropout and Academic Success* (UCI, id = 697).

Решение по прогнозу: направить студента группы риска к куратору. Цена ошибок C_FN : C_FP = 10 : 1.
Основная метрика — Macro-F1 (3 класса), порог подбирается для вероятности класса Dropout.
